# Lead Finder

Небольшое приложение для macOS (Apple Silicon): ищет публичные профили трейдеров на Myfxbook по стране и складывает их в таблицу. В аккаунт не входит и никому не пишет.

Скрытое окно приложения остаётся запасным путём, без отдельного Chrome. В этом режиме запросы к сайту делаются через `fetch` внутри страницы, поэтому уходят вместе с cookies. В user-agent нет Electron и имени приложения. Окно создаётся при старте (`show: false`, не в Dock) и живёт, пока приложение не закроют. «Начать поиск» использует его же. Если прокси меняется или окно падает, оно создаётся заново и снова остаётся скрытым. Если появляется «Just a moment» или Turnstile, страница сразу обновляется и дальше каждые 3 с, пока проверка не пройдёт или не нажмут «Стоп». Статус: «Cloudflare: обновляю страницу…». «Показать браузер» показывает это окно; закрытие его прячет, а не уничтожает.

Страницы списка идут по одной, пауза 0,8–1,5 с. Профили открываются до двух сразу; после первого 403 или 429 снова по одному. Картинки, шрифты и медиа не загружаются. На 403, 429 и таймаут — пауза от 1 минуты с удвоением, не дольше 30 минут. Уже проверенные ники и найденные лиды пишутся в userData (`lead-finder.json`), повторный запуск их не обходит заново.

Сайт в списке сейчас один — Myfxbook. Новый сайт добавляется отдельным модулем в `src/sources/` и строкой в `src/sources/index.js`.

## Запуск

Нужны Node.js 22 (или новее, включая 26) и macOS на Apple Silicon. Для разработки сойдёт и Linux. npm 11 не запускает скрипт установки Electron, пока пакет не указан в `allowScripts` — запись для `electron@33.4.11` уже стоит. Если бинарник всё равно не распаковался, `npm install` и `npm start` допаковывают скачанный zip через `ditto` на macOS или `unzip`.

```bash
npm install
npm test
npm start
```

По умолчанию страницы открывает Camoufox: скрытый процесс Python, профиль в userData (`camoufox-profile`), тот же прокси, что указан в приложении. Нужен Python 3.10–3.13 (на 3.14+ Camoufox не ставится). Одновременно не больше двух страниц, и они переиспользуются. Примерно каждые 300 страниц или когда память браузера выше 1,5 ГБ процесс закрывается и сразу стартует с тем же профилем, чтобы cookie проверки остались. Окно приложения остаётся запасным (`httpEngine`: `window` или `impit` в `lead-finder.json`).

```bash
npm run setup:camoufox
```

Скрипт создаёт `.venv-camoufox` через `uv` (или `python3.12`/`python3.13`), ставит `camoufox[geoip]` и скачивает браузер (`camoufox fetch`). В собранное `.app` Python пока не кладётся.

Первый запуск: откройте приложение, выберите страну, нажмите «Начать поиск». Ключ и регистрация не нужны. Отдельный Chrome не нужен.

Если Myfxbook недоступен из вашей страны, в строке «Прокси» укажите `socks5://host:port` или `socks5://логин:пароль@host:port` (подойдёт и `http://`). Адрес хранится в userData. «Проверить» показывает внешний IP. Новый прокси сразу пересоздаёт скрытое окно. Для SOCKS5 с паролем приложение поднимает локальный переходник на 127.0.0.1. Для HTTP-прокси с логином логин отдаётся через событие `login`.

На macOS данные приложения: `~/Library/Application Support/Lead Finder/`.

## Сборка

Неподписанный zip с `Lead Finder.app` для arm64:

```bash
npm run build
```

Архив появляется в `dist/Lead-Finder-arm64-mac.zip`. Подпись не ставится (`identity: null`).

Установка последней сборки из GitHub Releases в `/Applications` и снятие карантина:

```bash
curl -fsSL https://raw.githubusercontent.com/arturious/lead-finder/main/install.sh | bash
```

Первый запуск непроверенного приложения macOS может попросить открыть его через правый клик → «Открыть».
