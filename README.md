# Lead Finder

Небольшое приложение для macOS (Apple Silicon): ищет публичные профили трейдеров на Myfxbook по стране и складывает их в таблицу. В аккаунт не входит и никому не пишет.

Поиск идёт в фоне через [Patchright](https://github.com/Kaliiiiiiiiii-Vinyzu/patchright-nodejs) (`launchPersistentContext`, канал `chrome`). Запросы к сайту делаются через `fetch` внутри открытой страницы myfxbook.com, поэтому уходят вместе с cookies и отпечатком браузера. Свой user-agent и свой viewport не задаются. Профиль Chrome лежит в userData и переживает перезапуск. Окно по умолчанию не показывается: браузер в режиме new headless, тот же профиль и прокси. Если появляется «Just a moment» или Turnstile, три попытки идут там же: пауза от 5–8 с с ростом, затем обновление страницы. Если проверка сама не проходит, открывается обычное окно, чтобы её пройти, и после этого снова сворачивается. Следующий поиск опять без окна: cookies остаются в профиле.

Один запрос за раз, пауза 2–3 секунды. На 403, 429 и таймаут — пауза от 1 минуты с удвоением, не дольше 30 минут. Уже проверенные ники и найденные лиды пишутся в userData (`lead-finder.json`), повторный запуск их не обходит заново.

Сайт в списке сейчас один — Myfxbook. Новый сайт добавляется отдельным модулем в `src/sources/` и строкой в `src/sources/index.js`.

## Запуск

Нужны Node.js 22 (или новее, включая 26) и macOS на Apple Silicon. Для разработки сойдёт и Linux. npm 11 не запускает скрипт установки Electron, пока пакет не указан в `allowScripts` — запись для `electron@33.4.11` уже стоит. Если бинарник всё равно не распаковался, `npm install` и `npm start` допаковывают скачанный zip через `ditto` на macOS или `unzip`.

```bash
npm install
npm test
npm start
```

Первый запуск: откройте приложение, выберите страну, нажмите «Начать поиск». Ключ и регистрация не нужны. Если Google Chrome установлен, используется он. Если нет — первый поиск сам скачивает Chromium Patchright, прогресс виден в строке статуса.

Если Myfxbook недоступен из вашей страны, в строке «Прокси» укажите `socks5://host:port` или `socks5://логин:пароль@host:port` (подойдёт и `http://`). Адрес хранится в userData. «Проверить» показывает внешний IP. Новый прокси применяется со следующего нажатия «Начать поиск». У Chromium нет входа на SOCKS5 с паролем, поэтому в этом случае приложение само поднимает локальный переходник на 127.0.0.1 и отдаёт его Chrome.

На macOS данные приложения: `~/Library/Application Support/Lead Finder/`.

## Сборка

Неподписанный zip с `Lead Finder.app` для arm64:

```bash
npm run build
```

Архив появляется в `dist/Lead-Finder-arm64-mac.zip`. Подпись не ставится (`identity: null`).

Установка последней сборки из GitHub Releases в `/Applications` и снятие карантина:

```bash
curl -fsSL https://raw.githubusercontent.com/arturious/lead-finder/main/install.sh | bash
```

Первый запуск непроверенного приложения macOS может попросить открыть его через правый клик → «Открыть».
